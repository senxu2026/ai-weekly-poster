全球模型前沿

Global LLM
★
Google 发布 Gemini 4 Hydrogen（11/12）。事件摘要：面向日常编程与智能体执行，向 Gemini 应用、搜索、AI Studio 和 API 等入口推广；支持百万 Token 上下文，标准 API 每百万 Token 输入 1.50 美元、输出 7.50 美元。
产研影响判断：高频任务可优先比较完成耗时、有效结果和总成本，再决定是否调用更强的推理模型。
★
Claude Fable 5.2 与 Mythos 5.2 升级（11/09）。事件摘要：Anthropic 更新面向复杂技术任务的模型，称其编程、推理与视觉能力提升；标准 API 每百万 Token 输入 8 美元、输出 40 美元。Mythos 仍需通过专项验证获得访问资格。
产研影响判断：长任务可加入候选评测，同时核对接入资格、数据保留条件及实际任务成本。

国产模型与开源生态

China LLM
★
Qwen4-Max-Preview 开放限时预览（11/11）。事件摘要：通义新一代旗舰多模态模型支持图像、视频理解与工具调用，上下文为 1M Token；预览仅通过 Token Plan 提供，至 11 月 25 日结束，之后该预览端点下线。
产研影响判断：适合做对照试用；如要接入持续运行的业务，需提前安排预览结束后的模型替换。
★
文心 5.5 Flash Preview 上线 API（11/11）。事件摘要：模型总参数 2800 亿、每 Token 激活 140 亿，支持百万 Token 上下文，重点展示编程、3D 建模及办公能力。权重计划于 11 月 25 日开放，本周交付为预览服务。
产研影响判断：可用现有 CAD、Blender 或文档任务验证；三维演示能力仍需通过工程数据精度和可编辑性检查。

Agent 规模化落地

Agents
★
Claude 推出制造业工作插件（11/12）。事件摘要：17 项技能覆盖报价、质检、采购与故障诊断，连接 Autodesk Fusion、Infor、Microsoft 365 和 NetSuite；依据企业记录形成待审核成果。
产研影响判断：可借鉴“查业务数据—生成成果—责任人审核”的流程，优先落在报告和辅助分析场景。
▸
Claude Meetings 启动企业测试（11/12）。事件摘要：面向 Team 与 Enterprise 逐步开放 beta，当前支持作为可见参与者加入 Google Meet，记录纪要与行动项，并在会议中创建文档和白板；调用连接工具需获授权。
产研影响判断：会议助手开始覆盖成果整理和会中协作，试用宜核对参会知情、资料权限及任务归属。

算力 / 芯片

Compute
★
vLLM 公布 H3-Image 在 Rubin 上的部署测试（11/12）。事件摘要：在四 GPU、短提示词的特定测试中，原生 4K 生成中位延迟为 0.87 秒；6115 张/小时来自另一套吞吐配置，两项数字对应不同工况。
产研影响判断：硬件方案应分别评测单请求延迟、并发吞吐及图像质量，不能把不同工况的最好结果合并为同一指标。
▸
百度世界发布天池 1024 卡超节点（11/12）。事件摘要：百度在大会集中发布算力与模型进展，包括天池 1024 卡超节点及昆仑芯后续产品路线；这些属于大会发布口径。
产研影响判断：国产算力评估应看目标模型适配、稳定运行、交付周期与运维成本，再判断采购价值。

算电协同 · AI 与电力

★ 本期重点 / Power-Compute
★
黎明智算中心启动算电协同平台建设（11/11 报道）。事件摘要：据上观新闻，达卯科技与浦东环保能源合作，以黎明智算中心为首个项目，启动资源监控、运行分析、负荷预测与协同调度等平台建设；目前处于建设阶段。
产研影响判断：工程落地开始覆盖供冷与柔性资源管理，可跟踪其数据接口、调度边界和实际节能验收结果。
★
“十五五”新型储能实施方案公开（11/13 公开）。事件摘要：国家发展改革委、国家能源局公开方案及解读，提出全国新型储能规模达到 3 亿千瓦、平均时长约 3 小时，支持算力枢纽、算电协同及 AI 融合；通知成文于 10 月 29 日。
产研影响判断：新型储能目标口径不含抽水蓄能。可研究不同调节资源与算力负荷的协同，并按具体项目核算技术与经济条件。
产研视角：森旭可围绕抽蓄建设与运维，把设备状态、运行约束、调峰能力和能耗信息整理为可校验的数据，支撑 AI 辅助分析与算电协同方案研究。新型储能与抽水蓄能需按各自口径评估；机房供冷、快速波动治理和电网长时调节也应分别论证，以具体接口、运行边界和验收结果判断合作价值。

AI 编程 / Coding Agent

Coding
★
Antigravity 推出动态多模型 Orchestrator（11/12）。事件摘要：可在同一任务中由 Carbon 规划、Hydrogen 执行，遇到困难再切回；Google 在所公布的 Terminal-Bench 测试中称，接近 Carbon 成功率，同时少用约 24% 配额、快约 19%。
产研影响判断：可借鉴规划、执行、验证分工，收益需在本地任务集上验证，不能直接套用厂商测试比例。
▸
Qwen Code 更新订阅接入与仓库动态过滤（11/12）。事件摘要：本周发布 v0.26.8 至 v0.27.2 五个正式版，支持 Qwen 订阅账号登录；GitHub 频道新增仓库白名单和黑名单，减少无关事件进入 Agent 会话。
产研影响判断：团队接入宜先按负责仓库收敛事件范围，再比较自动处理质量和用量变化。

具身智能

Embodied AI
★
Runway 正式开放 Praxis-1 权重（11/11）。事件摘要：继 9 月预告后，27B 参数世界动作模型向所有开发者开放，权重及推理、微调代码采用 Apache 2.0 许可，可用于不同机器人形态的适配。
产研影响判断：开放模型降低研究门槛，现场应用仍取决于本体适配、训练数据、任务成功率及安全验证。
▸
ASUS 披露 Gallop 工厂训练进展（11/13）。事件摘要：Gallop 正在自有 EMS 工厂学习主板附件包装工位，结合人类示范、仿真和实际产线测试；客户试点计划为 2027 年，上市目标为 2028 年下半年。
产研影响判断：评估具身智能宜围绕一个完整工位的节拍、成功率和人工接管展开，区分验证进展与商业交付。

RAG / 长期记忆

RAG
★
MetaEncoder v1 扩展多模态检索（11/12 北京时间）。事件摘要：Meta 官方模型仓库提供文本、图像、视频帧及文档的统一编码与检索接口，输出 6656 维向量；模型卡列出 bf16 单张 80GB GPU 的运行条件。
产研影响判断：图纸、现场图片与文档混合检索增加了候选路线，需用业务问答集验证召回质量与部署成本。
▸
OpenViking 0.5.5 增强上下文存储与部署（11/13）。事件摘要：新增 PostgreSQL/pgvector 后端、多节点协调和快照路径历史索引，并可限制记忆召回范围及抽取类型；版本也调整了部分默认工具权限。
产研影响判断：企业记忆层需要可追溯、可隔离与可恢复；升级时应检查权限默认值及导入完整性。

政策 / 安全治理

Policy
★
自托管 Claude Managed Agents 开启私测（11/12）。事件摘要：Agent 控制框架、沙箱、凭据和会话历史可部署在企业云或本地环境，模型请求可走所选云服务或网关；这是执行平台自托管，并非模型权重本地部署。
产研影响判断：企业可更细地控制执行环境、网络与日志，仍需核对发送给模型的数据及服务商保留政策。
▸
百度推出模型交易平台“词元所”（11/12）。事件摘要：平台面向模型供应商及使用方，主打入驻前的模型指纹、能力、性能和可用性核验，以及上线后的抽检、监测与供应商信用评级。
产研影响判断：模型采购应把真实性、稳定性、服务承诺和来源追踪纳入比较，并保留独立业务验收。
