国产模型崛起

China LLM
★
Kimi K3 登顶 Arena 前端编程榜全球第一（7/16 发布，本周持续发酵）：2.8 万亿参数、100 万 Token 上下文，ELO 1,679 分超越 Claude Fable 5（1,631）与 GPT-5.6 Sol（1,618），7 个细分领域夺 6 项第一，成为首个超越所有闭源模型的开源模型。
中国开源模型在工程交付维度实现"从追赶到超越"的关键跨越。
★
全球科技领袖集体评价中国模型（7/21–27）：马斯克称"令人印象深刻"；UC Berkeley 教授认为中国模型仅落后美国 2–3 个月；Business Insider 称其"一夜之间改变了 AI 竞争格局"；Vercel CEO 实测后表示 Kimi K3 在真实 Web 工程交付上领先 Fable 5。
国际舆论从"质疑中国 AI"转向"正视中国开源实力"，对芯片/云/软件市场产生连锁影响。
▸
浙大发布"求是引擎"自主科研 AI 系统（7/22）：可端到端完成文献综述→假设生成→实验设计→编码→数据分析→迭代优化全流程，在真实光学实验中完成 206 步、21.5 小时自主研究，6 小时完成研究人员数周工作。
AI 从科研辅助工具升级为自主研究主体，"Loop Engineering"范式在中国率先落地验证。

智能体竞争焦点从"谁的模型参数大"转向"谁能让 Agent 真正完成任务"。

算力博弈

Compute
★
NVIDIA Vera Rubin 全面量产（7/21）：台积电 3nm、3,360 亿晶体管，288GB HBM4（22TB/s），推理算力 50 PFLOPS（5× Blackwell），每兆瓦 Token 吞吐量 10 倍提升；CoreWeave、Google Cloud、Azure、OCI 已完成 NVL72 部署，供应链日产能最高 1,000 座机架。
Vera Rubin 不只是一代新芯片，而是 7 芯片 5 机架的系统级重构，性能代差再度拉大。
★
英伟达拟为 OpenAI 提供 2,500 亿美元融资担保（7/26，WSJ）：支持 OpenAI 租用软银俄亥俄 10GW 超级数据中心（总投资约 5,000 亿美元），一期 2028 年完工；Anthropic、微软、Google 同时竞逐该项目。
"芯片商为云客户担保建数据中心"的循环融资模式成型，AI 基建金融杠杆急剧放大。
▸
国产算力创新密集亮相：壁仞科技推 NPO 光互连超节点，无问芯穹首创跨集群异构 PD 分离架构，商汤异构混合推理性价达 H 系列 1.25 倍；摩尔线程与极佳视界达成具身世界模型国产 GPU 训练合作。
国产算力从"能用"向"好用+创新架构"演进，推理成本持续下探。

RAG / 长期记忆

RAG
★
GraphRAG 从 Demo 到生产的工程化落地（7/23–26 行业热议）：核心经验——"轻量级模式"优先（只定义核心实体与关系）、从子系统切入验证、LLM 粗抽 + 规则精修 + 实体消歧构建图谱；实测多跳推理成功率从 15% 提升至 88%、事实准确率从 72% 提升至 94%。
企业知识库竞争从"谁的模型更大"转向"谁的知识图谱更准、更可控"。
▸
行业共识：不是所有场景都需要 GraphRAG——简单 FAQ 用传统 RAG 即可，只有跨文档推理、多跳查询、因果分析才值得引入图谱；推荐 Vector RAG + GraphRAG 双引擎混合架构。
RAG 选型需按场景分级，避免过度工程化，先跑通向量检索再试点图谱。

AI 编程 / Coding Agent

Coding
★
GraphRAG 重塑 AI 编程助手的代码理解能力（7/24）：通过构建 Class→Method→Exception→Dependency 知识链，AI 编程助手实现跨模块调用推理、影响面分析与故障根因追溯，多跳推理成功率从 15% 跃升至 88%。
AI 编程从"补全代码"进化为"理解系统架构"，知识图谱成为 Coding Agent 的记忆层。
▸
Kimi K3 编程能力获全球开发者验证（7/22–27）：Vercel CEO 实测确认在真实 Web 工程交付上领先 Fable 5；开源社区涌现大量 K3 + Cursor/Codex 协同开发案例，中国开源模型首次成为全球开发者首选编程工具之一。
编程领域成为国产模型"换道超车"的第一战场，开源生态加速正向循环。
▸
"Spec Coding"规范驱动开发成行业共识（7/25）：从 Vibe Coding 到 Spec Coding 的范式转移加速，Trellis 等工具解决 AI 编程"失忆"与失控问题；Skills 生态持续扩展。
规范驱动补齐可控性，编程 Agent 从"随手写"转向"按规格交付"。
