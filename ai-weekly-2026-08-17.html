国产模型崛起

China LLM
★
DeepSeek V4 Pro 正式版上线并涨价（8/13）：支持 100 万 Token 上下文、38.4 万 Token 输出；高峰时段价格为空闲 2 倍，Pro 输出 13.5→27 元/百万 tokens，Flash 输出 4.5→9 元。
DeepSeek 从低价竞争转向"能力+峰谷调度+生态接入"组合竞争。
★
Qwen 登顶全球开源模型下载量（8/14）：前 7 个月下载 20.45 亿次，生态衍生模型 15.1 万个；阿里同日开放 Qwen3.8 轻量与 Max 级权重。
国产开源模型从追赶进入主导，生态规模成为新的护城河。
▸
智谱 GLM-5.3 发布（8/14）：后训练带来编程能力提升，MiniMax 同日发布 Music3，苹果也被曝与阿里合作中国专属模型。
国产模型继续向编程、音乐、端侧与行业场景分化。

Agent 规模化落地

Agents
★
DeepSeek Harness 开源，45 小时获 10.5 万 Star（8/13）：MIT 协议，插件化架构，支持多模式和多 Agent 协作。
国内厂商开始在 Agent 执行框架层定义标准，直接对标 Claude Code 生态。
★
GPT-5.6 Multi-Agent v2 上线（8/16，海外参照）：主 Agent 可拆分任务给子 Agent，ChatGPT 前端同步提速。
Agent 编排成为模型厂商标配能力，竞争点从"会答"转向"会分工"。
▸
xAI 发布 Grok Bot 早期测试版（8 月中旬，海外参照）：每个 Agent 配独立云端虚拟机，可异步处理软件和票据任务。
Agent 正从对话工具演进为持续工作的云端数字员工。

算电协同 · 工程实践与资本布局新阶段

★ 本期重点 / Power-Compute
★
乌兰察布"星河基地"投产（8/12）：160MW 供电、百万 P 算力、绿电直供 80%，形成"绿电+储能+智算"闭环。
算电协同从规划进入运营，绿电直供成为智算中心核心卖点。
★
绿色算力大会定档 8/22 呼和浩特：字节跳动、中金数据、协鑫能科、寒武纪、宁德时代等将集中签约项目。
这是观察政策落地、项目签约和词元经济交易化的关键窗口。
★
天合富家 × 道客网络共建"Token 工厂"（8/14）：双方打造区域级算电协同平台，推进"绿电+算力"一体化运营。
Token 工厂开始成为算电协同的产品化表达。
★
协鑫能科参投 AI 生态基金（8/14）：出资 1 亿元参与 10 亿元基金，布局绿色电力与智能算力融合。
能源企业从供电方转向股权参与方，算电合作更深。
▸
算力西迁提速：青海成为绿色算电协同试点省，乌兰察布、哈尔滨等地智算项目继续扩容。
训练型算力正向绿电富集区迁移，"东数西算"进入绿电导向阶段。
▸
电力价值被 AI 重新定价：东莞证券预计国内算力中心耗电到 2030 年有望突破 8,000 亿 kWh，绿电直连项目审批提速。
AI 用电成为电力行业价值重估的新变量。
▸
中国移动智算规模扩张（8/13）：上半年智算总规模达 11.27 万 PFLOPS，在网资源使用率超 90%。
高使用率说明算力需求仍强，头部厂商资本开支还在加速。
🧭 产研视角：本周信号集中指向一件事：算力项目正在和绿电直供、储能调峰、Token 计量绑定。森旭可重点关注绿色算力大会项目签约、青海等试点省储能需求，以及乌兰察布/和林格尔集群的配套合作窗口。
