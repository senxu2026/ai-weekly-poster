全球模型前沿

Global LLM
★
Anthropic 拟在 IPO 前推出新一代模型（9/19，路透援引三名知情人士），直接对标 OpenAI GPT-6 Astra。
新模型已在内部最后调优，资本市场节点倒逼发布节奏，前沿代差窗口继续被压缩。
▸
OpenAI、Anthropic、DeepMind 宣布合作开展 AI 安全工作（9/16）。
竞争最激烈的三家在安全侧结盟，安全评测正在从各家自证走向行业共建。
▸
大模型价格三个月腰斩，7–9 月海内外厂商轮番发布新模型（9/19）。
能力溢价快速衰减，"聪明"本身不再是定价锚，采购窗口越往后越划算。
🇨🇳

国产模型崛起

China LLM
★
DeepSeek 发布 V4.1 Flash，上线不到 24 小时在 OpenRouter 处理约 1 万亿 Token；中国大模型周调用量已近美国 3 倍（9/17）。
DoorDash、Airbnb 等海外应用在用，国产模型第一次在全球调用量上形成代差优势。
★
阶跃星辰发布 Step Audio 3 系列语音大模型（9/15），含 Realtime / ASR / TTS 三款。
语音多模态成国产厂商差异化突破口，实时交互类场景的自研底座开始齐备。
▸
智谱拟登科创板募资不超 150 亿元，MaaS API 平台 ARR 约 17 亿、12 个月提升 60 倍，毛利率升至 18.9%（9/20）。
大模型公司首次把商业化曲线摊开给二级市场看，毛利率仍是最大问号。
▸
DeepSeek 新一轮融资后估值超 500 亿美元，阶跃星辰、月之暗面瞄准港股。
国产大模型进入集中资本化年，融资能力开始与模型能力同权重。

Agent 落地

Agents
★
华为云发布 Agentic Cloud 战略（全联接大会 2026，9/18），智果 AgentArts 已服务超百家企事业单位。
云厂商把 Agent 从工具升格为云战略主线，行业智能体开始有标准交付形态。
★
沙利文《2026 全球桌面 AI 智能体市场研究报告》：腾讯 WorkBuddy 中国个人端与企业端双榜第一（9/20）。
桌面智能体被单列成市场，"装在工位上的 Agent"进入第三方评测视野。
▸
国内 AI Agent 市场上半年营收约 205 亿元，同比增速 107%（9/18）。
规模化落地阶段的第一份成绩单，增速远快于大模型 API 本身。
▸
IDC《中国企业级通用 Agent 产品技术评估》发布，中国电信 TeleAgent 进第一梯队（9/17）。
运营商队伍进场，企业级 Agent 选型开始有标准化实测可依。

算力博弈

Compute
★
国产算力利用率分化，异构调度成新焦点（IDC 与信通院调研 250 家企业，9/15）：GPU 采购量持续增长，能稳定输出的 Token 却未同步增加。
买卡不等于有算力，调度与利用率正在取代采购量成为真实产能指标。
★
灵衢昇腾 950 智算集群服务 9 月 30 日国内上线（华为 HC2026，9/18）。
国产训练集群从发布走到可售可用，替代路径有了明确时间点。
★
黄仁勋：英伟达明年芯片销量将翻倍，GPU、CPU 供不应求（9/18）。
供给侧仍是卖方市场，国产替代窗口期被外部产能紧张同步放大。
▸
华为轮值董事长：2027 年中国 AI 模型训练将大规模转向华为（9/19）。
训练侧国产化被给出时间表，英伟达在华高端训练份额或继续承压。
🔋

算电协同 · AI 与电力

★ 本期重点 / Power-Compute
★
"算电协同"今年首次写入政府工作报告，并纳入《新型能源体系建设"十五五"规划》等多项能源专项规划（9/15）。
低延迟要求把推理算力推向中东部，用电压力从技术议题升为国家规划议题。
★
中电联：AI 赢得了芯片，输不起一次停电（2026 能源绿色发展大会，9/16）。
供电可靠性成为智算中心的硬约束，储能与调峰配置从选配变刚需。
★
商汤临港 AIDC 获信通院"算效+算电"双 5A 认证，首批算电协同测评认证成果落地（9/12）。
算电协同开始有可量化标尺，认证等级将成为智算中心招商与融资的凭证。
▸
工信部、发改委联合印发《电子信息制造业发展"十五五"规划》（9/15）；美国弗吉尼亚州签署数据中心问责令，管透明度、环境审查与能源成本（9/18）。
中美同期把数据中心用电纳入监管，绿色算力合规成为跨境共同门槛。
🔎 产研视角：算电协同已从"写进规划"转入"开始算账"——测评认证、供电可靠性、绿电配比都开始有可量化标尺。这正是森旭抽蓄电站"为电网与算力做储能调峰"的价值锚点，可继续把 "蓄能智筑 + AI" 作为政策级叙事的切入点。

记忆 / 上下文

Memory
★
华为云："算力之外拼记忆"，企业级 AI 产品矩阵把记忆能力摆到与算力同级（9/18）。
Agent 竞争从单次推理转向跨会话持久化，记忆层开始被当作独立产品卖。
★
Claude Code 自 9 月 19 日起原生支持 AGENTS.md，向 OpenAI 提出的项目指令文件格式靠拢。
上下文入口标准化，同一份项目规则可在多家 Agent 间复用，迁移成本下降。
▸
开放 Agent Skills 标准落地：云栖大会 Skill 已上线多款 AI 平台，主流 Agent 可直接调用。
能力以 Skill 为单位分发，生态位从"接口"上移到"可复用技能包"。

AI 编程 / Coding Agent

Coding
★
智谱 ZCode"静默上传代码"风波升级，已有企业发函追责（9/20）。
源于一次普通磁盘清理被发现，编码类 Agent 的数据边界成为企业采购红线。
★
Claude Code 项目功能升级，多智能体并行处理大型任务（9/19）。
从单线程结对编码转向任务并行，大型重构的可行性边界被推开。
▸
Arc 推出 AI 编码代理 Arc Studio，自然语言数分钟生成含前端、后端与合约的全栈应用（9/18）。
垂直领域的"一句话出应用"继续下沉，模板化场景的交付成本快速塌陷。

具身智能

Embodied AI
★
地瓜机器人完成 4 亿美元 C 轮融资（9/17），强化旭日芯片全算力段布局与全链路软件平台。
资本押注"卖铲人"而非整机，机器人算力底座成为新的确定性环节。
★
智身科技完成数亿元 B 轮，阿联酋磊石资本领投；截至今年 6 月累计量产超 1.5 万台，覆盖电力、石化、消防、应急等行业（9/20）。
中东资本进场，"能干活的机器人"路线跑通行业场景，电力赛道已在其中。
▸
上半年中国具身智能赛道融资超 935 亿元，同比约增 5 倍（中国机器人峰会，9/18）。
峰会主论调转向"褪去资本喧嚣、奔赴真实场景"，评测体系建设被提上日程。
▸
丰田计划在工厂部署 40 万台机器人；小鹏发布人形机器人 IRON 自动化产线（9/20）。
制造业自有场景成为人形机器人最先兑现的订单来源。

政策 / 安全治理

Policy
★
《人工智能安全治理框架 3.0》发布（9/14 国家网络安全宣传周开幕式），聚焦智能体风险前置管控。
同期美国三大 AI 巨头呼吁减速研发，中方选择以制度前置替代整体刹车。
★
信通院联合中国政法大学发布《智能体治理研究报告（2026 年）》。
智能体被单独立题治理，权限、留痕与责任归属是企业侧最先要补的功课。
▸
最高人民法院出台涉人工智能纠纷案件审理意见（9/18）。
司法口径落地，AI 纠纷从无先例走向有裁判规则。
▸
美国参议员提出《禁止超级人工智能法案》（9/16），要求 NIST 先立安全标准。
立法侧出现"永久禁止"级提案，中美治理路径分化进一步显性化。
