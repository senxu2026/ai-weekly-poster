全球模型前沿

Global LLM
★
Gemini 4 Carbon 发布，首批面向网络防御伙伴（10/28）。事件摘要：Google 公布新一代前沿模型，在 Artificial Analysis 智能指数 v5.0 中得分 59；本周先向部分网络防御机构开放，随后逐步扩展可信合作伙伴，并非已向所有用户开放。
产研影响判断：选型应同时核对能力、接入资格和实际可用时间，榜单领先不等于能够立即上线。
★
Mistral Large 4 开放权重进入企业部署视野（10/29）。事件摘要：继 10 月初 API 预览后，Mistral Large 4 权重已上线官方模型仓库。模型为原生多模态 MoE，总参数约 1 万亿、激活约 520 亿，采用专门的生态开放权重许可。
产研影响判断：开放权重增加部署自主性，仍需核对商用许可、显存与推理成本，不能按激活参数估算全部硬件需求。

国产模型与开源生态

China LLM
★
Qwen Code 连发三个正式版本（10/29）。事件摘要：官方周报披露本周发布 v0.26.1、v0.26.2、v0.26.3，合入 357 个 PR；补齐 PR 跟进、后台会话接入与 Web Shell 管理等能力。
产研影响判断：国产工具竞争已延伸到日常工作流，可用现有项目验证任务连续性与协作体验。
▸
Qwen Code 支持导入 Codex 记忆（10/29）。事件摘要：新增记忆迁移能力，可先预览、挑选内容及保存范围，再由工作区模型整理后写入本地记忆；同时修正模型能力识别与服务商模型清单。
产研影响判断：积累的业务约束和项目知识开始具备迁移路径，团队宜保留可读、可导出的知识底稿。

Agent 规模化落地

Agents
★
GitHub 将 Agent 工作接入项目交付流程（10/28）。事件摘要：GitHub 发布 Copilot app 与 Copilot projects，支持跨仓库组织云端任务，并可在应用、编辑器、命令行及网页间跟进同一会话。
产研影响判断：试点可从修复一个缺陷、完成一项需求开始，验收任务结果，并记录人工接管次数。
▸
Copilot Automations 加入事件与定时触发（10/28）。事件摘要：自动化任务可按仓库事件或计划启动，覆盖问题分流、代码审查等工作；系统可根据执行结果提出流程改进，交由用户审核。
产研影响判断：重复性工作适合逐步自动化，需先定义触发条件、完成标准与人工处理入口。

算力 / 芯片

Compute
★
NVIDIA 与 Oracle 规划多吉瓦级 AI 超级集群（10/27）。事件摘要：双方宣布扩大 OCI 上 Vera Rubin NVL72 系统部署，并引入 Vera CPU，面向训练、推理及智能体任务；多吉瓦规模属于扩展计划。
产研影响判断：算力评估要覆盖 CPU 工具执行、网络与 GPU 利用率，不能只比较单卡性能或把规划当成已投运容量。
▸
RTX Spark 更新本地模型与后台 Agent 工具（10/28）。事件摘要：NVIDIA 公布语音转写模型、LFM3 模型支持及资源管理更新；RTX Spark 笔记本最高配置 128GB 统一内存，可在前台应用与后台 Agent 间分配 GPU 资源。
产研影响判断：会议转写、文档处理等任务可评估本地运行，重点测中文效果、延迟及与三维应用共用资源时的表现。

算电协同 · AI 与电力

★ 本期重点 / Power-Compute
★
常州“光储充算”示范项目正式投运（10/28；10/30 报道）。事件摘要：CNESA 储能研究平台披露，常州经开区“智云常经开”项目以固态变压器为能量路由核心，将光伏、储能、超充及 AI 算力负荷集成，验证绿电消纳与冲击负荷平抑。
产研影响判断：可关注从能源设备到负荷调度的实际接口、运行数据与验收指标，形成工程场景的可复用参考。
▸
多吉瓦算力扩展带来电力配套要求（10/27）。事件摘要：NVIDIA 与 Oracle 的联合公告将 AI 超级集群扩展目标提升至多吉瓦规模，负载同时覆盖模型训练、推理及智能体应用。
产研影响判断：推断：大规模算力建设将增加对电源、接网及调节资源的要求；具体储能技术和配置时长仍需按负荷与电网条件论证。
产研视角：森旭可围绕抽蓄建设与运维，梳理调峰能力、设备状态和运行约束等可量化信息，为算电协同方案提供业务依据。抽水蓄能的长时调节与算力负荷的快速波动分属不同时间尺度，需与电网、快速储能和控制系统协同，不能直接替代机房侧快速电能质量治理。

AI 编程 / Coding Agent

Coding
★
Qwen Code 可持续跟进 PR 修复（10/29）。事件摘要：新增 /autofix-pr，能跟进构建失败、评审意见和分支冲突，修复后执行仓库检查；后台监视支持查看、恢复及停止，执行仍受审批设置约束。
产研影响判断：可先在低风险仓库验证，观察检查通过率、误改率和评审返工，逐步明确自动提交的边界。
▸
Octoverse 显示多模型协作成为常见用法（10/28）。事件摘要：GitHub 披露，61% 的 Copilot 用户使用过不止一种模型；付费用户 9 月使用 47 种模型，单一模型请求份额均未超过 25%。
产研影响判断：研发工具选型应比较实际任务的交付质量与成本，保留按任务切换模型的能力。

具身智能

Embodied AI
★
智元发布 GO-3 Preview 具身基座模型（10/29）。事件摘要：官方称模型贯通预训练、后训练与部署后学习，以 WRAM 架构统一任务理解、状态预测和动作生成，并计划于 2026 年底全面开源。
产研影响判断：关注真实场景中的任务迁移和持续学习；预览版与厂商评测成绩仍需经过现场验证。
▸
智元创新日发布交互模型与开源操作系统（10/30）。事件摘要：智元公布 WITA-OMNI 多模态交互模型，覆盖视觉、听觉、语言、表情及肢体动作；同时发布灵渠 OS 1.0，宣布开源并捐赠开放原子开源基金会。
产研影响判断：工业机器人接入正从单机能力扩展到软件生态，合作评估宜看接口兼容、维护周期与可交付版本。

RAG / 长期记忆

RAG
★
Google 提出 Sleep Framework 持续学习研究（10/27）。事件摘要：研究将交互与离线记忆巩固交替进行，尝试把短期信息写入长期参数，同时缓解学习新知识时的遗忘；目前属于研究成果。
产研影响判断：这与外部知识库检索是不同路线。企业近期仍应做好知识版本、权限和溯源，持续观察其成熟度。
▸
CORAL 用任务检查点减少长任务上下文负担（10/30 北京时间）。事件摘要：论文提出先保存进度与已验证事实，再由 Agent 主动清理冗余上下文。作者实验中，输入 Token 消耗较 ReAct 基线减少至约六分之一至七分之一。
产研影响判断：可借鉴“保存任务状态后再续跑”的方法；实验降本比例不能直接套用到企业项目。

政策 / 安全治理

Policy
★
上海发布新一代智能制造行动方案（10/27 公开）。事件摘要：方案提出到 2028 年开发 10 个先进适用的垂域大模型，推出 300 个以上高水平智能体，并推动 8000 台人形机器人进工厂；文件成文日期为 10 月 22 日。
产研影响判断：行业智能体和工业数据成为明确方向；制造业政策可作相邻行业参考，具体项目仍需核对适用范围。
★
OpenAI 披露前沿模型行为偏离监测体系（10/29）。事件摘要：监测范围扩至训练、评估、内部使用及特定外部部署，通过分层审查识别越权与欺骗行为；外部部署会依产品调整，且不常规将告警升级给人工审查。
产研影响判断：企业 Agent 需要权限控制、执行日志、异常暂停与人工处置机制，不能只依赖模型自述。
