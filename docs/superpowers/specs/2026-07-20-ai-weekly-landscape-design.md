# AI 信息周报横版看板设计说明

## 目标

将 `ai_weekly_poster_2026-07-20.html` 从纵向长页重排为适合桌面浏览和长图导出的横版信息看板，同时完整保留现有全部文字内容。页头与页脚统一使用用户提供的“森旭服务”透明 PNG Logo。

## 桌面布局

- 设计基准宽度为 1920px，内容区使用四列网格。
- 页面保持自适应宽度，不锁定固定高度；目标是在完整保留内容和可读性的前提下，将当前约 4231px 的高度显著压缩为更接近方形的横向看板。
- 页头改为左右结构：左侧为森旭服务 Logo，右侧为周报标题、英文主题与日期。
- 四个数据指标保持一行四列。
- “本期三条主线”使用三列方块，与数据区形成紧凑的概览带。
- 九个内容栏目进入四列拼贴网格：
  - 普通栏目默认占一列。
  - “算力与物理 AI”“AI 资本与市场”“算电协同”作为重点模块占两列。
  - 重点模块内部使用两列内容流，减少纵向堆叠。
- 卡片采用较小圆角、紧凑间距和清晰边框，强化方块化信息板观感。

## Logo 与素材

- 将用户提供的透明 PNG 复制到项目内的 `assets/senxu-service-logo.png`。
- 页头使用完整横版 Logo，不再以文字模拟品牌。
- 页脚复用同一 Logo，并与周报名称、信息来源和免责声明形成横向排列。
- Logo 使用 `object-fit: contain`，避免裁切、拉伸或改变品牌色。

## 字体与可读性

- 全部原文逐字保留，不删减摘要、不隐藏栏目。
- 桌面端正文保持可阅读字号，通过减少空白、调整行高和增加横向栏数控制高度。
- 标题、标签、重点标记和产研视角保持现有视觉层级。
- 不采用固定 16:9 画布，以免为了容纳全部内容而将文字缩得过小。

## 响应式规则

- 大屏：四列布局。
- 中等宽度：两列布局，重点模块仍可跨两列。
- 手机：单列布局，所有模块顺序与原文一致；Logo、标题和日期纵向排列。
- 不通过横向滚动承载正文。

## 内容与结构约束

- 保留全部九个栏目、四个指标、三条主线、两个产研视角、信息来源与免责声明。
- 内容顺序与语义不变，仅调整 HTML 容器和 CSS 布局。
- 页面继续保持单文件可打开；Logo 作为同目录相对路径资源加载。

## 验收标准

- 桌面端 1920px 视口下呈现四列横版看板，整体高度明显短于当前版本。
- 页头和页脚均显示新 Logo，比例正确、背景透明。
- 页面文本与修改前对比无缺失。
- 1440px、中等宽度和 390px 手机视口均无溢出、遮挡或不可读内容。
- 浏览器控制台除可忽略的 favicon 请求外无资源加载错误。
- 可导出一张完整 PNG 长图，并通过视觉检查确认所有栏目和页脚完整。
