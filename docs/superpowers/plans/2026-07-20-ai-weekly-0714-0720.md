# AI 信息周报（0714-0720）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 生成一份覆盖 2026-07-14 至 2026-07-20 的可核验、响应式浅色 AI 信息周报 HTML，并创建每周一 09:00 自动更新任务。

**Architecture:** 以现有 HTML 为只读视觉模板，先构建经过日期与来源核验的资讯清单，再复制其 CSS 与页面结构并替换内容。使用静态检查和真实浏览器双端截图验证成品；自动化任务每周检索上一自然周并生成新文件。

**Tech Stack:** HTML5、CSS3、公开网络检索、Playwright/Chromium、Codex 自动化。

## Global Constraints

- 输出文件为 `AI信息周报（0714-0720）.html`，不得覆盖原模板。
- 只收录 2026-07-14 至 2026-07-20 发生或正式发布的信息。
- 页面不展示逐条来源链接；页脚汇总来源机构并标明数据截至 2026-07-20。
- 保留原浅色视觉体系、响应式布局、森旭品牌与算电协同重点卡。
- 文件须为无脚本、无远程字体依赖的单文件 HTML。
