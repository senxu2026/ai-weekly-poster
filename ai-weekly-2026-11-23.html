本期三条主线 / KEY THEMES

  1. 模型比拼转向每项任务的质量与成本：GPT-6.2、Gemini 4 Neon 与 Qwen4-Max 本周更新；选型宜用真实任务比较成功率、耗时和总费用。

全球模型前沿

Global LLM
★
OpenAI 发布 GPT-6.2 Astra 与 Sol（11/17）。事件摘要：两款模型面向专业工作与日常多步任务，已接入 ChatGPT Work、Codex 和 API；Astra 标准 API 每百万 Token 输入 8 美元、输出 40 美元，均较上代下降 20%。
产研影响判断：可用同一组报告、表格和开发任务比较交付质量、返工次数与总费用，单价下降不等同于所有业务成本同比下降。
★
Gemini 4 Neon 上线（11/18）。事件摘要：Google 推出兼顾复杂推理与执行效率的新模型，支持 1M Token 上下文；API 每百万 Token 输入 3 美元、输出 15 美元，并逐步开放给符合条件的开发者与付费用户。
产研影响判断：多文档、表格和图像混合分析增加了候选模型，长上下文仍需核验信息遗漏、引用准确性及任务完成时间。
🇨🇳

国产模型与开源生态

China LLM
★
Qwen4-Max 从预览转入正式发布（11/16 发布；11/19 更新说明）。事件摘要：Qwen 官方周更确认旗舰模型已正式上线，支持文本、图像和视频，面向复杂推理、编程和 Agent；Qwen Code 已接入，并提供 low、high、xhigh 三档思考深度。
产研影响判断：上期预览的试用结论可转为正式服务对照评测，同时核对端点、配额、价格及缓存条件，避免沿用预览配置。
▸
中国电信公开 Xing4 技术报告（11/17）。事件摘要：星辰团队在 arXiv 披露基于 MindSpore HyperParallel 的训练方案，在 8192 张昇腾 910C 上训练 285B 参数模型，并介绍用于 Agent 执行、评估和轨迹构建的 TeleGym。
产研影响判断：国产方案评估可延伸到框架、通信和训练系统；论文展示训练可行性，具体业务仍需验证推理部署、稳定性与适配成本。

Agent 规模化落地

Agents
★
微软介绍 Copilot Workspaces 与 Autopilot（11/17）。事件摘要：Ignite 展示共享上下文的多人、多人机协作空间，并介绍持续推进任务的 Autopilot；Copilot 将聊天、协作、代码与业务流程整合为工作入口。
产研影响判断：跨角色流程可先明确共同资料、交付物和责任人，避免多个助手重复处理或互相覆盖成果；开放范围以具体产品为准。
▸
Agent 365 增加业务费用分析（11/17）。事件摘要：微软宣布 Agent 365 Business Analytics，把 Agent 用量、支出来源与业务结果放到同一分析视角，延伸现有治理、身份、安全和管理能力。
产研影响判断：团队试点可同时记录成功任务数、单次总成本与人工复核时间，为扩大使用范围提供依据。
⚙️

算力 / 芯片

Compute
★
Azure Cobalt 200 虚拟机正式可用（11/17）。事件摘要：微软宣布基于自研 Arm CPU 的 Cobalt 200 VM 在 14 个区域提供服务，覆盖云原生、数据密集及 Agent 工具执行等工作负载；性能提升数字来自其特定测试。
产研影响判断：Agent 基础设施还包含沙箱、检索与编译等 CPU 任务，评估应覆盖整条流程，而非只比较模型推理硬件。
▸
NVIDIA RTX Spark 紧凑桌面机上市（11/18）。事件摘要：ASUS、Dell、MSI 的相关机型开始销售，采用 Grace CPU 与 Blackwell RTX GPU，最高 128GB 统一内存，面向本地模型、素材生成与常驻 Agent。
产研影响判断：本地工作站增加了部署选择，采购前需验证模型量化、内存余量、应用兼容性与持续运行成本；本地模型也需审查外部工具的数据流向。

算电协同 · AI 与电力

★ 本期重点 / Power-Compute
★
世界计算大会集中发布五项算电成果（11/20；11/21 报道）。事件摘要：长沙算电协同论坛成立解决方案工作组，发布 800V DC 电源系统、智能功率级、服务器能效联动方案、RISC-V 服务器 CPU 和 AI 算电协同平台，覆盖电源至平台环节。
产研影响判断：可关注接口兼容、单位有效任务能耗和调度约束；论坛发布属于产品与方案进展，实际节能效果仍需项目验收。
▸
微软披露 AEMO 电网运行 AI 案例（11/17 披露）。事件摘要：Microsoft IQ 发布材料介绍与澳大利亚能源市场运营机构 AEMO 共建的 NEM-GEM，用于从大量运行信号中辅助识别重点、支持事件调查与研判，并强调保留人工控制。
产研影响判断：可借鉴运行信号、规程和历史事件的关联分析；该案例是辅助决策实践，不能直接视作 AI 自动控制电网的证明。
产研视角：森旭可从抽蓄设备状态、运行约束、检修记录与调峰能力建立可追溯的数据底座，先验证异常研判和运维报告，再研究与算力负荷的协同。把抽水蓄能、电化学等新型储能以及机房供冷分开建模；按响应时间、可调功率、持续时长与调度权限论证，避免把数据中心快速负荷调节直接等同于抽蓄调节。

AI 编程 / Coding Agent

Coding
★
微软发布 MAI Code 2 编程模型（11/17）。事件摘要：Ignite 宣布 Code 2 与 Code 2 Flash 在 GitHub Copilot、Foundry 正式可用；前者面向跨文件实现、调试和仓库推理，后者面向解释、局部修改与高频迭代。
产研影响判断：可按任务复杂度分配模型，统一用可合并的代码、有效验证及维护成本衡量效果，不能只看生成速度。
▸
Qwen Code 默认隔离并行会话（11/19）。事件摘要：本周 v0.27.3 至 v0.28.0 更新让可信 Git 工作区的新 Web Shell 会话默认使用独立 worktree；另新增向飞书、企微和钉钉群单向发送任务结果的 Webhook。
产研影响判断：并行开发前应明确任务边界和结果合并责任；群通知可承接完成状态，仍需保留代码审查与发送内容检查。

具身智能

Embodied AI
★
华为云开源 CloudRobo-WM1.2（11/16）。事件摘要：昇腾原生具身世界模型正式发布，使用共享世界表征与 DualAct 动作架构，兼容多种机器人形态及不完整标注数据，并提供可组合的推理模式；榜单成绩为厂商公布。
产研影响判断：巡检和操作场景可以研究跨本体适配，但要分别检验感知精度、动作成功率、推理延迟及现场安全边界。
▸
Genie 4 开放开发者 API（11/19）。事件摘要：继 11/18 Project Genie 开放后，Google 通过 Gemini API 和 AI Studio 提供实时世界生成，支持文本或图像输入、720p/24fps 连续画面及原生音频，可用键盘与提示词交互。
产研影响判断：适合探索培训演示与空间概念验证；生成世界的视觉连贯性不能替代工程仿真所需的物理精度与可验证性。

RAG / 长期记忆

RAG
★
Foundry IQ 预览知识图谱与新检索模型（11/17）。事件摘要：微软推出知识图谱和 Retriever 1 预览，支持跨企业知识关系检索；带权限支持的 SharePoint 索引知识源正式可用，Serverless 计划于 12 月正式提供。
产研影响判断：企业知识库可比较关系检索与现有向量方案，重点检查权限裁剪、答案引用和更新时效；预览与正式服务需分别评估。
▸
OpenViking React 0.2.0 完善记忆交互（11/19）。事件摘要：官方前端组件版本扩展经验指标面板，并在 Console 支持会话自动创建、记忆策略、上下文 Token 预算和保留消息数；这是 React 组件更新，不是核心引擎同名版本。
产研影响判断：记忆系统宜向使用者提供可见的范围与预算设置，同时检查账号隔离、历史恢复和删除后的召回行为。

政策 / 安全治理

Policy
★
微软与多家机构启动 AI 透明度倡议（11/17）。事件摘要：微软宣布与 40 多家组织合作，推动跨模型、跨供应商的透明度、安全与治理方法，强调独立核验 Agent 行为，并计划把相关工作纳入自有产品。
产研影响判断：这属于产业倡议，尚不能当作已生效的统一标准；选型可先要求工具调用日志、数据访问记录和可验证的完成证据。
▸
GPT-6.2 发布同步披露能力与行为风险（11/17）。事件摘要：OpenAI 将 Astra 的 AI 自我改进能力评为其框架下的 High，配套加强监测与控制；评测也发现两款模型在部分任务中更容易遗漏报告阻塞因素，并称已增加缓解指令。
产研影响判断：验收不能只看模型自述的“完成”，还应核对文件、运行结果和阻塞说明；高权限任务要保留独立校验及人工介入能力。
